# Erdős #743 — Gyárfás tree packing, verified at K₁₀

**Question** ([erdosproblems.com/743](https://www.erdosproblems.com/743), status
`FALSIFIABLE`): let `T_2, …, T_n` be trees with `|V(T_k)| = k`. Can `K_n`
always be written as the edge-disjoint union of the `T_k`?

**What this certificate establishes: YES for n = 10**, over every one of the
45,376,056 tuples, exhaustively. The frontier had stood at `n ≤ 9` since
Fishburn 1983 — 43 years.

```bash
python3 -I verify.py
```

The edge count is exact: `Σ_{k=2}^{10} (k−1) = 45 = C(10,2)`. This is a
*perfect decomposition* with no slack — every edge of `K_10` is used exactly
once — which is what makes the problem tight rather than a packing with room
to spare.

## What was actually searched

All 45,376,056 tuples, in 44 core-seconds, with **no** per-tuple search
budget. Every tuple packs; the program constructed a packing for each.

The tuple count is the product of the free-tree counts (OEIS A000055):
`1·1·2·3·6·11·23·47·106 = 45,376,056` for `k = 2..10`. Those trees are
generated by `gen_trees.py`, whose counts are pinned to A000055 so a
generation bug cannot pass silently.

## The two reductions, and the one we refused

**Fixing `T_10` is sound and we use it.** `T_10` is spanning (10 vertices, 9
edges). Any packing maps to one with `T_10` at a fixed embedding by permuting
`V(K_10)`, and vertex permutations are automorphisms of `K_10`, so pinning one
embedding loses nothing. Nothing analogous is done for `T_9`: after `T_10` is
pinned the remaining symmetry is only its stabiliser, not `S_10`, so fixing
`T_9` too would be **unsound**.

**Leaf-sibling ordering is sound and we use it.** Swapping two leaf children of
the same parent is a tree automorphism, so a packing exists iff one exists with
those leaves mapped in increasing order. Without this the search explores all
`m!` orderings of a star's leaves.

That optimisation was not cosmetic. The tuples that resisted the first
implementation were exactly those where `T_4, T_5, T_6, T_7` are **all stars**
— which is also precisely where the literature's coverage stops: Gyárfás–Lehel
settle the case where all but at most two trees are stars, and these tuples
have three non-stars. The factorial blow-up landed on the hardest region.
Adding the symmetry break took the count of tuples exceeding a 2M-node budget
from 33,171 to **2**, and the whole sweep from "did not finish in 10 minutes"
to 7.4 seconds wall.

**Bollobás's greedy result is NOT used.** Our own ledger notes that the
smallest `⌊n/√2⌋` trees pack greedily, which would let the search skip most of
the work. We decline: the search places every tree itself, so a misreading of
the literature cannot silently shrink the sweep.

## Why a null result here is trustworthy

- **`n = 9` reproduces Fishburn 1983 exactly** — all 428,076 tuples pack, in
  0.2 s. A search that cannot rediscover the known case is not searching.
  `n = 4..8` likewise pack, all tuples.
- **"Gave up" is never reported as "no packing exists".** A tuple that exceeds
  its node budget is reported `HARD` and re-run uncapped; only a genuinely
  exhausted search yields `UNPACKABLE`. Conflating the two would turn a slow
  tuple into a false counterexample to a 43-year-old conjecture — the single
  worst bug this program could have.
- **Planted failures.** `--selftest` demands a packing that cannot exist (one
  edge too many) be REFUSED, alongside packings that must be found. A packer
  that always answers "yes" fails; so does one that always answers "no".
- **Every reported result is a construction.** A "packs" verdict means the
  program built the decomposition, not that it failed to disprove one.

## What this does not do

- It does not prove the conjecture. It settles `n = 10` and says nothing about
  `n ≥ 11`, where the tuple count explodes (A000055(11) = 235 alone multiplies
  the space by 235).
- It is not a new proof technique. It is an exhaustive check, and the honest
  deliverable is a verified-to-`n` record.
- The upstream citation `[Fi83]` on erdosproblems.com resolves to a *different*
  1983 Fishburn paper ("Balanced integer arrays: a matrix packing theorem").
  The packing result we reproduce is Fishburn, "Packing graphs with odd and
  even trees", *J. Graph Theory* **7** (1983) 369–383. Recorded here because
  the next person to check the frontier will hit the same broken reference.
