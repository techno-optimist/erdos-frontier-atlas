# Candidate-22 q6 microbox deletion fence

This scratch certificate strengthens the earlier whole-cell fence to arbitrary
**measurable carving** of the fixed 22-cell q=6/M7 geometric union.  It is a
finite, support-specific obstruction: any retained measurable subset with
normalized 12-dimensional volume strictly larger than the inherited benchmark
`(7/24)^6` contains a **common-offset realization from one of the 30,425
frozen positive balanced eight-row packet families** in `matching_ledger.json`.
Therefore it cannot support the stated raw-canonical modular-torus coercivity
inequalities for an arbitrary real-valued physical potential.

The result relies only on the explicit positive matching ledger.  The
CP-SAT/channel search used to discover it, and any claim of completeness of
that search, are deliberately not theorem inputs.
The ledger's `channels_sha256` and `enumeration_solutions_used` fields are
hash-checked discovery provenance only; the deletion implication uses neither
channel-path completeness nor any solver-negative result.

## Frozen packet matching

Every packet uses the balanced unit template in `template.json`:

```text
(4,5;0), (4,7;1), (6,7;2), (5,6;3),
(2,3;4), (1,2;5), (0,1;6), (0,3;7).
```

Each endpoint label occurs exactly twice and each center occurs once.  Thus
the sum of the eight potential terms cancels identically.  The ledger contains
exactly 30,425 packets, each with eight distinct physical q6^12 digit boxes,
and no box occurs in two packets.  It records all six local digit-pairs for
every vertex, allowing both replays to reconstruct every midpoint carry and
every positive raw cost.


## Measurable-carving lemma

Write `D=[0,1/6)^12`.  A ledger vertex with digit vector `d` represents the
half-open physical microbox `d/6+D`.  Let `E` be any measurable retained subset
of the 22-cell union.  For packet `p` and its vertex `i`, define

```text
A[p,i] = { t in D : d[p,i]/6 + t belongs to E }.
```

For a shared offset `t`, every modular midpoint identity remains valid: `t`
cancels from each midpoint defect, while all points stay inside their original
half-open microboxes.  If all eight points were retained, summing the eight
raw-canonical coercivity inequalities would cancel the potential and leave a
strictly positive sum of row costs.  Hence

```text
intersection_i A[p,i] = empty                         (up to a null set).
```

The union bound on the shared offset cube gives

```text
sum_i measure(D minus A[p,i]) >= measure(D)
```

for each packet family.  The matching's `8 * 30,425` physical boxes are
globally disjoint.  Translation/Fubini therefore identifies the sum across
all packet families with disjoint pieces of the deleted set and gives deleted
volume at least `30,425 * measure(D)`.  This is a measure statement; it does
**not** claim that any whole physical box must be deleted.

The exact box-volume arithmetic is

```text
full C22 mass                    = 1,370,520
forced deleted box volume        >=   30,425
maximum retained box volume      <= 1,340,095

1,340,095 * 64 - 85,766,121 = -41 < 0.
```

Thus every packet-free measurable carving is strictly below the inherited
gate `(7/24)^6`.

## Replays

```text
python3 -I verify.py --self-test
python3 -I independent_replay.py
```

`verify.py` recomputes the cell mass, all 243,400 physical boxes, every
midpoint/carry/cost row, endpoint balance, global matching disjointness,
strict common-offset lift, and the union-bound/Fubini deletion arithmetic.
Its planted controls include an intentionally duplicated locally valid packet,
which is rejected only by the global-box-disjointness check.  The independent
replay is separately written and imports neither the primary verifier nor any
discovery code.

`constants.json` is a checked manifest and is never regenerated by either
replay.  It hash-binds every payload artifact in this directory; as usual for
a hash manifest, it does not attempt an impossible self-hash.

## Scope

The conclusion is limited to the fixed 22-cell geometric union in
`candidate.cells`, under the raw-canonical modular-torus coercivity convention
and arbitrary measurable carving of that union.  It does not cover geometric
deformations, replacement cells, recursive state, ordinary Euclidean midpoint
claims, or integer transfer.  It gives no new bound on `r_3(N)` and does not
solve Erdos Problem 142.
