# Mathematical publication scope

This directory contains mathematical source catalogues, theorem statements,
proofs, exact mathematical controls and explicitly conditional graph overlays.
External claims are kept separate from locally replayed evidence. No update here
changes a canonical problem status or a previously published certificate.

Retained implementation areas are `research-sprint/`, `research-next/`,
`swarm/`, `upstream-update/` and `lead-phase/weighted-formal/`. The bundle
checker enforces that directory boundary. New areas require an explicit scope
review and an updated checker; a mathematical keyword does not by itself
justify publishing an application study.

Do not add confidential application data, operational run summaries, model
outputs, prompt or task transcripts, deployment records or private source
identities. Reusable mathematical results must be stated with their hypotheses
and supported by mathematical proofs or explicitly bounded controls.

Source snapshots may carry upstream URLs, authorship and their original public
metadata. Keep their licenses and exact bytes. New notices must date corrections
and distinguish retracted arguments from false mathematical statements.
