# p-bands and Type B2b first slice

**Not a solution of #699.**

If \(p=P^+(\mathrm{odd\_part}(\binom n3))\) divides \(n(n-1)(n-2)\), then \(n=mp+r\) for \(r\in\{0,1,2\}\). Band \(m\) is that family.

Known hits: \(m=2\) contains \((10,5)\); \(m=5\) contains \((65,15)\); \(m=9\) only the B1 overlap \((65,15)=(9\cdot7+2)\).

**Type B2b first slice** \(8p\le n<10p\) (\(n/10<p\le n/8\)): \(m=8\) empty through \(p<400\); global band through \(n=3000\) empty.

Remainder: \(P^+\le n/10\), then \(i\ge 4\).
