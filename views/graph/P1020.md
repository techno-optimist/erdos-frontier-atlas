- our summary: Erdos matching conjecture [Er65d]: for f(n;r,k) = max edges in an r-uniform hypergraph on n vertices with no k pairwise disjoint edges, f(n;r,k) = max(C(rk-1,r), C(n,r)-C(n-k+1,r)) for all r >= 3. Both terms are achieved by explicit constructions; Erdos-Gallai proved r=2.
- witness: CONCRETE. An r-uniform hypergraph H on n vertices (a list of r-subsets) with no k pairwise disjoint edges and strictly more edges than the conjectured maximum. At the smallest live cell that is a subset of the 715 4-subsets of [13].
- smallest untested case: r=4, k=3, n=13 -- the smallest cell not covered by ANY range listed on the problem page (small-n side: trivial for n<kr=12, Kleitman at n=12, Frankl [Fr17] reaches only n <= 3*(4 + 1/(2*4^9)) = 12.0000006; large-n side: the best listed for r=4 is Frankl-Luczak-Mieczkowska n > 2k*r^2/log r = 69.3, i.e. n >= 70).
