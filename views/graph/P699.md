**Erdős Problem 699.** Is it true that for every $1 \le i < j \le n / 2$ there exists a prime $p \ge i$ with $p \mid \gcd\big(\binom{n}{i}, \binom{n}{j}\big)$?

### `S:triage:699` — triage verdict **TARGET** (finite_handle_triage, 2026-07-26)

- our summary: Is it true that for every 1 ≤ i < j ≤ n/2 there exists a prime p ≥ i with p | gcd(C(n,i), C(n,j))?
- witness: A triple (n, i, j) with 1 ≤ i < j ≤ n/2 such that no prime p ≥ i divides both C(n,i) and C(n,j). Verified by Kummer's theorem — p | C(n,k) iff adding k and n−k in base p produces a carry — so the check is pure exact integer arithmetic on base-p digits, with no big-integer factoring and no floating point.
- smallest untested case: n = 10^7 + 1 (general n), outside the special families n = 2^k for k ≤ 27 and n = 3^m + 1 for m ≤ 17, both already covered to ≈1.34×10^8.
