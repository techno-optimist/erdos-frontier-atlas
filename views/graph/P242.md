## STATEMENT (Apache-licensed, Lean-derived)

For every $n>2$ there exist distinct integers $1 ≤ x < y < z$ such that $\frac 4 n = \frac 1 x + \frac 1 y + \frac 1 z$.

### `S:triage:242` — triage verdict **WALL** (finite_handle_triage, 2026-07-26)

- our summary: Erdős–Straus: for every n>2 there exist distinct 1<=x<y<z with 4/n = 1/x+1/y+1/z.
- witness: A single integer n>2 (WLOG prime) together with a certified exhaustive search showing no (x,y,z) works. The witness is really the *exhaustion*, not the number: 'no solution' for one n is itself a nontrivial finite check over divisors of n·x.
- smallest untested case: n prime, n > 10^18, restricted to n in one of Terzi's 198 bad residue classes mod 120120 (equivalently n = 1,121,169,289,361,529 mod 840 after Mordell). Smallest concrete untested n is the least prime above 10^18 in those classes.
- known frontier: Verified for all n <= 10^18 [MiDu25], cited in the erdosproblems remarks. Prior partial results: Obláth [Ob50] (n+1 divisible by a prime 3 mod 4), Mordell [Mo69] (6 bad classes mod 840), Terzi [Te71] (198 bad classes mod 120120), Vaughan [Va70] exception count <= x·exp(-c(log x)^{2/3}), Elsholtz–Tao [ElTa13] f(p) <= p^{3/5+o(1)}.
- search-space estimate: One decade past the record: pi(10^19)-pi(10^18) ~ 2.05e17 primes x (198/120120 = 0.165% surviving Terzi) ~ 3.4e14 candidate n, each needing its own divisor search over x in (n/4, 3n/4] — >= 3.4e14 heavy checks vs a ~1e12 op budget.
- verification cheap and exact: no
- verdict reason: Frontier is already 10^18 and 100+ years of congruence sieving has removed 99.8% of n, so every remaining case is by construction a hard one. Extending by even one decade needs ~3.4e14 individual exhaustive searches, ~300x over budget before per-case cost. Worse, a positive witness is not a small object: refuting one n requires certifying an exhaustive divisor search, so criterion 3 (cheap exact verification of a witness) fails outright.
- no move applies mechanically
