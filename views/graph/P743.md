- our summary: Gyárfás tree packing conjecture: for any trees T_2,...,T_n with T_k having exactly k vertices, K_n is the edge-disjoint union of the T_k.
- witness: A counterexample witness is a specific tuple of 9 unlabeled trees (T_2,...,T_10), each given as a parent array / edge list, that admits no edge-disjoint packing into K_10 — accompanied by an exhaustive refutation (search tree). A positive witness (per tuple) is the packing itself: an assignment of each tree's edges to distinct edges of K_10. Note the edge count is exact: sum_{k=2}^{10}(k−1) = 45 = C(10,2), so this is a perfect decomposition, not a packing with slack.
- smallest untested case: n = 10. Fishburn [Fi83] settled n ≤ 9. The n=10 instance is the 45,376,056 tuples (T_2,...,T_10) of unlabeled trees.
- known frontier: Fishburn, "Packing graphs with odd and even trees", J. Graph Theory 7 (1983) 369–383 — verified n ≤ 9. This is still the frontier cited on erdosproblems.com/743 (page curated 2026).
