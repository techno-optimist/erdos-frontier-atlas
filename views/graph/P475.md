- our summary: Graham's conjecture: every finite A subset of F_p\{0} has an ordering a_1,...,a_t whose partial sums are all distinct.
- witness: Concrete: a prime p and a set A ⊆ F_p\{0} of size t such that NO ordering has distinct partial sums. Certified by exhaustive backtracking over <= t! orderings (integer arithmetic mod p only).
- smallest untested case: t = 13 (proved for all t <= 12 by Costa-Pellegrini [CoPe20]; t=13 is the first open size). Since t >= p-3 is also proved, the smallest genuinely open instance is t=13 in F_17: C(16,13) = 560 sets. The first awkward one is t=13 in F_47: C(46,13) = 5.0x10^11 sets.
- known frontier: True for all t <= 12 (Costa-Pellegrini 2020, arXiv 2003.05939; literature also states 'true for subsets of size k<=11 in cyclic groups of prime order'). True for p-3 <= t <= p-1 (Hicks-Ollis-Schmitt). Asymptotic ranges: t <= log p/loglog p [Kr24]; t <= e^{c(log p)^{1/4}} [BeKr24]; t <= e^{c(log p)^{1/3}} [CoDe26]; 1 <<_alpha t <= p^{1-alpha} [PhSa26]; p^{1-c} <= t <= (1-o(1))p [BBKMM25]; t >= (1-o(1))p [MuPo25].
