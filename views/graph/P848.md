## STATEMENT (Apache-licensed, Lean-derived)

Is the maximum size of a set $A ⊆ \{1, \dots, N\}$ such that $ab + 1$ is never squarefree (for all $a, b ∈ A$) achieved by taking those $n ≡ 7 \pmod{25}$? This asks whether `Erdos848 N` holds for all $N$ (formulated using `A ⊆ Finset.range N`). This was solved for all sufficiently large $N$ by Sawhney in this note. In fact, Sawhney proves something slightly stronger, that there exists some constant $c>0$ such that if $\lvert A\rvert \geq (\frac{1}{25}-c)N$ and $N$ is large then $A$ is contained in either $\{ n\equiv 7\pmod{25}\}$ or $\{n\equiv 18\pmod{25}\}$.

### `S:triage:848` — triage verdict **WALL** (finite_handle_triage, 2026-07-26)

- our summary: Is the maximum size of A ⊆ {1,…,N} with ab+1 never squarefree (all a,b ∈ A) achieved by taking n ≡ 7 (mod 25)?
- witness: Two-sided and asymmetric. A falsifying witness is a set A ⊆ {1..N} with |A| > ⌈(N−7)/25⌉ and ab+1 non-squarefree for every pair — cheap and exact to verify by squarefree-sieving ab+1 ≤ N²+1. But closing the DECIDABLE gap requires the other side: an exact maximum-clique certificate for every N in the remaining interval, on the graph with vertices {a ≤ N : a²+1 not squarefree} (density ≈0.105N) and edges ab+1 not squarefree. That is NP-hard per N.
- smallest untested case: N ≈ 10^3 upward. Alexeev reports straightforward approaches only reached 'a few hundred'; MalekZ's claimed structured verification to N = 10^7 was reviewed and judged likely incorrect (N. Sothanaphan, 16 Mar 2026) so it cannot be counted. The interval to close runs up to N_0 ≈ 2.64×10^17.
- known frontier: Sawhney's note settles the problem for all sufficiently large N, originally at the ineffective-in-practice N_0 = exp(1420) ≈ 10^617. A GPT-5.4-Thinking-driven explicit-threshold campaign on the #848 thread (N. Sothanaphan, Mar 2026) walked N_0 down 7×10^17 → 3.3×10^17 → 2.64×10^17, with cross-model pingpong (old-bielefelder) suggesting ~2.9×10^17 is roughly the structural floor of that proof method. Upper bound |A| ≤ (0.108…+o(1))N (van Doorn), sharpened to ≈0.105 (Weisenberg).
