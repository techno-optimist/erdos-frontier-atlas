Briefcase · Erdős #699

Decide a whole row from the positions of its primes

#699 asks whether, for every i < j ≤ n/2, some prime p ≥ i divides both C(n,i) and C(n,j). Pick a row (n, i). The page factors n, n−1, …, n−i+1, marks every prime p ≥ i by the position it came from, and runs the proved reduction. Most rows are settled by three smooth parts and one inequality, with no factoring at all. Every number is exact (BigInt).

The positional table

Row t shows n − t = St·Rt. Every block M = pe in Rt is a prime p ≥ i of C(n,i). If p does not divide C(n,j), Kummer's theorem forces j mod M ≤ t.

    Why this works
    
    
    
      
    Write n − t = St Rt. Rt is the product of prime powers qe ∥ n − t with q > i, or q = i and e ≥ 2.
        If no prime p ≥ i divides both C(n,i) and C(n,j), then:
    
      
    (a) R0 | j. Write j = R0m with 1 ≤ m ≤ S0/2.
    
         (b) Rt divides ∏r≤t(t m − r S0) for every 1 ≤ t < i. This is exactly the positional condition.
    
         (c) 4(n−1) ≤ S0² S1.
    
         (d) If j < n/2, then 6√3 (n−1)(n−2) ≤ S0³ S1 S2.
    
         (e) If j = n/2, then Rt = 1 at every odd t. In particular n − 1 is smooth.
    
      
    So for each fixed i ≥ 3, at most O(X1/3 logπ(i)X) values n ≤ X can fail.
    
    
    
  
    

  
    
    
    Informal proof with exact computational checks. No novelty claim, not formalized, and not a solution of #699.
      Primality is proven below 3.3·1024. Above that it is a strong probable-prime test, and the page says so.
